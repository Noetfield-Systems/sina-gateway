# Gateway V4 — Interest-based discovery

This release separates editorial interest collections (16 fields), public technical references, and the existing Founder-approved case manifest. An interest field is a discussion invitation, not a venture or investment listing. The public build must never ingest the private portfolio inventory. Existing approved-case generation, inquiry API and ownership boundaries remain intact.

The homepage provides filters, search, expandable topic questions, context-aware inquiry routing, a curated technical collection and dated journal links. Category artwork is original illustrative SVG, not product screenshots. Actual project photography and screenshots must come from authorized assets. The 30 role-based audience hypotheses are maintained privately; they are not human research or observed conversion data.

The Web3 collection links to the already-published engineering dossier, public source and model. No claim of audited or live Mainnet execution is made. The current case manifest remains unchanged until scoped authority and materials are established.

Release checks: npm test; npm run build; anonymous homepage and collection navigation; responsive layouts; inquiry persistence and receipt; authorized screenshot validation. Keep existing repository, hosting and inquiry database. No separate OS, CRM or runtime is introduced.
